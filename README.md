# Сайт актёра Тимура Абитова

Готовый сайт для GitHub Pages. Уже вписаны: почта, видео-визитка (Rutube), шоурил (Яндекс.Диск), параметры, фильмография и театр.

## Что осталось сделать: загрузить фото

Сайт ждёт фотографии в папке `images/` со СТРОГО такими именами:

- `headshot.jpg` — главное фото (4-е из ваших, в чёрной куртке) — показывается в Визитке и как постер видео
- `photo-01.jpg`, `photo-02.jpg`, … `photo-12.jpg` — галерея (любое количество до 12; чего нет — рамка скроется сама)

Как загрузить: в репозитории откройте папку `images` → Add file → Upload files → перетащите переименованные фото → Commit changes.

⚠️ Переименуйте файлы на компьютере ПЕРЕД загрузкой (правый клик → Переименовать).

## Настройки

Всё в `index.html`, блок `window.TA_CONFIG` в самом верху: почта, ID видео Rutube, ссылка на шоурил, Formspree ID, соцсети.

## Как редактировать на GitHub

index.html → иконка карандаша → правки → Commit changes. Через 1–2 минуты сайт обновится.
⚠️ Не редактируйте в Microsoft Word.
